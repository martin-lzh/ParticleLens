# Security Policy

## Supported versions

Security fixes are provided for the latest release on `main`. The
`development` branch may contain unreleased changes.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature:

https://github.com/martin-lzh/ParticleLens/security/advisories/new

Do not open a public issue for a suspected vulnerability and do not include
private microscope images, credentials, or personal data. Include affected
versions, reproduction steps, impact, and any suggested mitigation.

The maintainer aims to acknowledge a report within seven days. Timelines for a
fix and coordinated disclosure depend on severity and reproducibility.

## Scope

Relevant reports include browser data exfiltration, unsafe image parsing,
runtime-cache integrity bypasses, path traversal in the local server, release
artifact tampering, and dependency vulnerabilities. Scientific accuracy
questions without a security impact belong in the detection issue form.
